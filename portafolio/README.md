# Maria Fernanda — portafolio.exe

Portafolio personal hecho con React y Vite. La interfaz combina tonos ciruela, pixel art, brillos y detalles inspirados en una computadora retro.

## Página publicada

[Ver el portafolio en GitHub Pages](https://al069840.github.io/TAREAS/portafolio/). Se publica automáticamente al actualizar esta carpeta en la rama `main`.

## Iniciar en local

```bash
npm install
npm run dev
```

## Personalizar

- Los textos, proyectos, etiquetas y enlaces están en `src/main.jsx`.
- Los colores, distribución y versión móvil están en `src/styles.css`.
- El botón de contacto enlaza al perfil de GitHub porque no se proporcionó un correo.

Antes de publicar, reemplaza cualquier texto que quieras ajustar y agrega un enlace al demo o repositorio de Kirbyoncé si ya lo tienes.
