# Entre Hilos

Página en React para aprender a crear amigurumis desde cero. Incluye una lista de materiales, cinco etapas de aprendizaje, un patrón de práctica y un glosario.

Las dos fotografías de `public/images` son las imágenes originales proporcionadas para el proyecto y se incluyen sin editar.

## Ejecutar en tu computadora

Necesitas Node.js y npm. En una terminal, entra a esta carpeta y ejecuta:

```bash
npm install
npm run dev
```

Abre la dirección local que aparezca en la terminal.

Para generar la versión de producción:

```bash
npm run build
```

## Página publicada

La versión final se publica automáticamente en [GitHub Pages](https://al069840.github.io/TAREAS/) cuando se actualiza esta carpeta en la rama `main`. El flujo de publicación está en `.github/workflows/deploy-entre-hilos.yml` en la raíz del repositorio.
